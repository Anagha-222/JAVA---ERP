# Java Enterprise Resource Planning (ERP)

## Project Overview
The Java ERP system is a simple enterprise management application developed to manage business operations such as employees, products, inventory and sales.

## Technologies Used
- Java 23
- HTML
- CSS
- JavaScript
- VS Code
- HTTP Server

## Features
- Employee management
- Product management
- Inventory management
- Sales management
- Dashboard interface
- Java backend integration
- Web-based forms

## Project Files
- `Main.java` – Main application class.
- `Employee.java` – Employee details and operations.
- `Product.java` – Product information.
- `ERPSystem.java` – ERP management operations.
- `ERPServer.java` – Java backend server.
- `index.html` – Web interface.

## How to Run

1. Install Java JDK 23.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the Java files:

```bash
javac Main.java Employee.java Product.java ERPSystem.java ERPServer.java
```

5. Start the server:

```bash
java ERPServer
```

6. Open the website using Live Server.

Backend server:

`http://localhost:8081`

This project provides a basic ERP solution that demonstrates how Java can be used to manage different business operations through a web interface.
